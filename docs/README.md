# 疑云牌局 · 手机直连实验版

保留中文《政变》与紧凑手机布局，2–6 人。最终 `single/index.html` 包含全部界面、规则、PeerJS 1.5.4 和二维码代码，不依赖本机游戏后台、数据库或前端 CDN。

## 开始

1. 用 Safari / Chrome 打开静态网址，输入昵称，点“创建手机房间”。
2. 房主点“邀请朋友”，分享二维码、链接或 6 位房间码。
3. 朋友打开同一网址，输入昵称并加入。至少两人入座后房主开始。
4. 保存自己的个人恢复码；换页面时可恢复座位。房主只能在原浏览器和原存档所在设备上恢复整桌牌局。

## 电脑是否需要开着

不需要。GitHub Pages 提供页面，房主手机维护牌局。房主手机必须保持浏览器页面在前台；锁屏、切应用或退出会暂停或中断牌局。返回原页面后会尝试恢复，其他玩家请保留页面等待。

## 网络条件

使用免费的 PeerJS 公共信令、Cloudflare STUN 和经用户同意的 Open Relay（Metered）公开免费 TURN 中继。中继转发端到端加密的数据包，可看到 IP 等连接信息，无法读取手牌明文。其公开 static-auth 凭据由网页生成，服务可用性与免费政策取决于提供方。无法保证大陆各运营商或复杂 NAT 跨网可连。失败会显示明确提示和“重新连接”。不保证微信或 QQ 内置浏览器，建议 Safari / Chrome。

## 本机演练

首页展开“没有网络？本机多人演练”，选择人数并开始。轮到下一人时出现私密交接屏。全部代码已在 HTML 内；页面加载完成后，此模式不需要联机服务。

## 隐私与恢复

房主保存权威状态，其他玩家只接收自己的手牌与公共信息。房主属于可信参与者，可以在其浏览器调试工具中查看完整状态，适合朋友之间娱乐。浏览器本地存档不等于云端备份；清除房主浏览器数据会丢失存档。恢复码不要发给其他玩家。

## 开发与验证

Node.js >=22.14，仅开发构建需要：

```sh
npm ci
npm run check
npm test
npm run build
```

18 项规则、信息隔离、操作幂等、恢复和热座交接测试通过。真实 Android+iOS 手机跨网测试尚需使用者完成，不将电脑浏览器测试写成手机实机通过。

本项目通过单个静态 HTML 部署。网页地址不包含自己的临时隧道，也不调用 `/api/game`。
